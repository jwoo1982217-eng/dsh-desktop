# DSH桌面文件工作台

桌面端独立插件，在原DSH侧栏加入“文件”。文件区、已有项目工作区和本人授权的共享目录统一浏览；普通UTF-8文本支持预览、带版本检查的保存，提供名称/内容搜索、文件导入导出、新文件、新目录及普通文件改名。共享目录默认只读，读写模式需要本人明确确认；取消映射不删除源目录。

本包只使用原DSH主机和当前用户的文件权限，不另建Linux环境，也不改变AI会话的工作区、fs/bash权限或模型配置。DSH文件区位于本包自有storage下；账号、聊天、浏览器登录数据和本包元数据不作为通用浏览区。文件名/内容按数据呈现，HTML/SVG不在宿主同源执行。

复用alpha.4的workspaceRegistry和fs provider；缺失时明确报告不可用，不静默换成更宽权限。文本保存必须匹配先前版本，外部修改后保留编辑草稿并提示重新载入。单文件导入最多64MiB、文本编辑最多2MiB；同名导入/新建/改名不覆盖原文件。目录改名与永久删除不在本批支持范围，避免不可靠的目录覆盖语义。

共享目录映射只保存引用、身份和代次，主机目录被替换或权限失效后要求重新确认。普通Node路径防护不是对抗同UID恶意进程的OS强沙箱。本包不做后台全盘索引，不发模型请求，不复制现有聊天或凭据。

接口、实际测试、安装及加载状态分别保留；见API.md与后续交付回执。新插件走独立内容指纹目录及原profile的一个bundle注册，不运行旧停服务/重签App的部署器。正式桌面加载验证之前不把源测试或复制说成已生效。
