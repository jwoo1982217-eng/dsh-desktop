DSH 桌面版 0.1.6 · Windows x64

适用系统：64 位 Windows 10 / Windows 11。
双击安装包，安装后打开桌面或开始菜单中的 DSH。
运行环境、记忆引擎、OpenCode 已包含，无需另装 Node.js。
默认安装到当前用户的 LocalAppData\Programs\DSH，不需要管理员权限。

首次使用需在模型或 JetHub 设置中登录/填写自己的配置。
本安装包不包含任何人的账号、API 密钥、聊天或记忆。
新对话记忆范围与跨 Agent 来源可分别选择，包含 ZCode。
浏览器面板调用系统 Chrome 或 Edge；模型调用和在线登录需要联网。

升级或卸载前，请先关闭 DSH 窗口；关闭窗口会结束本应用启动的后台服务。
账号、聊天、记忆等数据默认保存在 %USERPROFILE%\.dsh；卸载保留这些数据。
菜单“DSH → 显示数据文件夹”可查看实际位置。
如设置了 DSH_HOME 环境变量，则使用该目录。

如果提示启动失败：
1. 从菜单“DSH → 重新连接”重试。
2. 若提示 3080 端口被占用，请关闭旧版 DSH 后重试。
3. 日志位于 %APPDATA%\DSH\logs\desktop.log。
