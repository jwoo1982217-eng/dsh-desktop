# DSH 电脑版

基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的电脑版适配源码，固定使用官方 `0.2.1-alpha.1` 预览版核心。程序在电脑本机运行，通过浏览器使用；提供 Jet Hub、ChatGPT 会员授权、API 网关、Noema、技能和手机远程连接。

电脑与 [DSH 手机 APK](https://github.com/jwoo1982217-eng/dsh-phone) 分别安装。手机本机可以独立使用，也可以通过 Pocket 扫码在 App 内打开家里电脑的同一个 DSH 实例，查看电脑对话并操作电脑工作区。

## 安装与启动

需要 Git、Node.js 24.11+（含 npm）。在终端依次执行：

```sh
git clone https://github.com/jwoo1982217-eng/dsh-desktop.git
cd dsh-desktop
npx --yes pnpm@10.34.6 --dir desktop-runtime install --frozen-lockfile
node scripts/install-desktop.mjs
node scripts/start-desktop.mjs
```

启动后自动打开浏览器。Mac 后续双击 `desktop/start.command`，Windows 使用 `desktop/start.cmd`，Linux 使用上面的启动命令。源码目录需要保留，安装后的程序入口引用它。

已有账号、对话、技能、自定义预设和设备配对保存在本机 `~/.dsh`，安装器保留这些数据。升级前等 AI 任务结束并停止旧进程，再按 [完整安装说明](desktop/README.md) 操作。重复打开启动脚本会复用已运行的电脑服务。

## 手机连接电脑

1. 电脑「设置 → 手机访问」打开 Pocket；外出使用时点「开启公网访问」，确认提示后等待公网二维码。
2. 手机使用 0.1.55 或更新版，点「电脑 → 扫码连接电脑（Pocket）」，扫描二维码并在 App 内输入电脑显示的访问密码。
3. 下次点「电脑」会打开保存的连接；顶部「手机」可切回手机本机。地址变化时从「服务 → 设备连接」重新扫码。

安装器自带 Pocket 2.10.6。完整步骤、原加密配对、API 同步和手机网关见 [手机配对使用说明](docs/phone-pairing.md)。电脑、DSH 和 Pocket 隧道需保持在线。

手机访问电脑的页面包含旧 Android WebView 兼容层，补齐模型列表排序、聊天历史查找与授权窗口的浏览器方法。部分旧 WebView 在模型设置页只显示说明、没有配置卡片时，请使用手机 0.1.30 或更新版本，并按安装说明更新电脑程序。

手机上传菜单已与「＋」联动，提供图片和文件入口；标准技能 ZIP／SKILL.md 从文件入口自动导入。窄屏用量弹窗在屏幕内定位并独立滚动。手机本机图片解码适配需要安装 0.1.31 或更新 APK。

实时连接以本机服务的实际可达性为准，手机浏览器的互联网离线提示不会暂停回环地址的重试。页面从缓存恢复时重新建立连接，回到前台时恢复断开的连接，读取已有回复而不重发任务。手机本机模式使用 0.1.32 或更新 APK；电脑模式需要更新此仓库程序，等现有 AI 任务结束后重启。

网页已添加防自动翻译标记，避免 Chrome 翻译改写正在更新的聊天节点，造成回复正文空白。界面使用 DSH 自身的语言支持；更新网页后刷新现有页面即可重新显示已保存的回复。

## 账号、模型与技能

- 在电脑「设置 → Jet Hub」配置账号与模型；ChatGPT 会员需要本人在电脑浏览器完成授权。
- 普通 API 配置可以由手机预览后同步到电脑；网页登录账号各端保存，也可以通过「手机模型网关」调用手机上的账号。
- 同名会员模型按来源区分：电脑自己的「ChatGPT 会员」直接调用；共享模型名称以「手机网关 · 」开头，需要手机在线。已有会话选择按各自记录保留，切换当前会话会同时保存新对话的默认模型。
- 电脑技能放在 `~/.dsh/skills/<技能名>/SKILL.md`，保存在本机用户目录。
- 电脑模式使用电脑的工作区、对话和工具；手机本机模式使用手机的数据。

## 源码与验证

本仓库独立发布电脑版源文件，不包含 Android 工程、APK、手机原生库或私人运行数据。`phone-account` 和 `phone-qq` 是与手机共用的插件源码，保留名称以兼容已有模块与锁文件；安装电脑版不需要 Android SDK 或 NDK。共享界面资源位于 `peer/presentation.*` 与 `peer/browser-compat.js`。

已在 macOS arm64 验证依赖冻结安装、空白 profile 安装、升级保留设置、真实核心启动、认证、重复打开、原生终端和 Noema。Windows/Linux 尚未进行本项目实机验收。远程协议测试使用模拟账号和临时工作区；用户手机的实际公网连接需要配对后确认。

```sh
node --import ./scripts/desktop-test-imports.mjs --test scripts/desktop-install.test.mjs scripts/desktop-upstream.test.mjs peer/*.test.mjs
```

源码来源及许可证见 [来源说明](SOURCES.md)。公开说明只使用占位地址和临时测试数据；实际账号、密钥、浏览器登录链接与配对链接留在使用者本机。

## Preset 广场与插件管理

设置中新增 7 套工作流和 9 个技能；在新对话中选择 Preset。电脑可预检查固定 NPM 版本后安装/更新、启停和卸载插件；手机安装沿用原生备份试装，增加实际清单管理。飞书可在广场配置，图像/视频依赖缺失时显示限制并支持进入已连接电脑处理。详情见 [工作流与插件说明](peer/workflow-hub/README.md)。

## Jet Hub 同厂牌多账号接续

在同一厂牌面板添加多个独立账号并完成各自授权。同一上游的同一模型持续使用当前可用账号；额度不足或账号限流时，自动由下一个有该模型权益的账号接续。停用、模型暂不可用、凭据损坏和不可续期的过期账号会跳过；设置页、模型目录读取与凭据续期不切换账号。原有永久积分锁定继续限制账号资格。

ChatGPT 会员同样只使用已授权且官方目录支持当前模型的连接。请求在交付正文或工具输出前失败可以换号；已有输出的请求不会换号重放。账号选择按上游和模型在进程内保存，两端分别维护；重启后重新从可用列表选择。

ZCode 账号卡片可选择自动、每日赠送 Start Plan、个人 BigModel 套餐、机构流量和实际可用的团队来源。登录后读取账号关联的现有凭据，无需手填 API Key，不自动创建云端密钥；机构流量可能产生对应费用，按用户明确选择的来源调用。

桌面和手机聊天输入框按回车换行，点击「发送」提交；Ctrl/Cmd+Enter 仍可快捷发送。中文输入法确认、菜单选择、任务运行中的排队/追问、上传和停止行为保留。


## MCP 服务与模型调度

「设置 → MCP 服务」管理 stdio、HTTP、SSE 与手机 MT 连接，内置浏览器已接入模型工具。调度程序可探测允许的模型线路、自动派单、复用原生子代理并记录用量与验收；未知费用不视为免费。详见 [功能与使用说明](peer/mcp-manager/README.md)。等待任务结束后重启加载。

电脑版右侧「浏览网站」与 AI 浏览器工具共用 DSH 专用网站登录资料。遇到安全验证加载失败，可点击「登录窗口」，在可见 Chrome 窗口中自行完成登录，再刷新原网页。该窗口沿用同一个 DSH 浏览器上下文，关闭标签不会主动清除登录；普通 Chrome/Edge 的个人资料仍是独立的。本功能已在 macOS Chrome 验证登录及工具读取，其他网站的风控和浏览器版本仍需逐项验证。


## GitHub 公开版的 Gemini OAuth 配置

本公开版本移除了内置 Google OAuth 客户端 ID 和密钥。使用 Gemini 浏览器授权前，请在启动环境配置自己的 `CMDC_PAK_GOOGLE_CLIENT_ID` 与 `CMDC_PAK_GOOGLE_CLIENT_SECRET`；其他供应商不受此配置影响。不要将实际值提交到仓库。配置方式见 [公开版配置说明](docs/github-public-config.md)。

## 2026-10-10：ZCode 额度与领取状态修复

ZCode 账号卡片和用量徽标跟随已选的额度来源。个人套餐与团队套餐分别读取所属账号、组织及项目的配额，显示上游套餐等级、5 小时窗口和每周窗口的剩余额度；不同窗口不相加，也不作为 Start Plan Token 余额。查询失败显示错误，避免误报余额为零。

每日赠送状态使用每个账号自己的凭据查询。已经领取但尚未生效的额度单独显示北京时间和待生效数量，不计入当前可用 Token；刷新来源会同时更新账号卡片和徽标。验证码及人工领取要求保留。

WorkBuddy 国际版添加账号时，打开独立临时浏览器资料的普通 Chrome/Edge 窗口，避免沿用上一账号的登录状态；该授权窗口不使用浏览器调试控制。其他网站的右侧浏览器仍沿用其专用网站资料。

电脑版聚合模型按当前首选上游读取上下文容量；无法取得有效容量时保留兼容默认值，上游明确拒绝上下文长度时交给宿主压缩。此项为电脑版更新，手机版源码保持其原有聚合实现。

## 2026-10-11：普通 JSON 大文件上传

聊天「上传文件」支持单个分析文件 64 MB、一次最多 8 个且合计 128 MB。大 JSON/文本完整保存在本机，草稿引用文件位置，助手可分段读取或直接解析原文件；小文本、图片及技能导入仍使用已有入口。选择文件后等上传完成，写分析要求，再点击发送；失败保留草稿并可重试。

此次同步包括文件读取模块、加密转发的大文件支持及安装器依赖。此处为源码更新，已运行的桌面实例需正常更新后加载；安卓版同一实现已在联想平板 0.1.63 实测完整上传及读取约 5 MB 中文 JSON。
