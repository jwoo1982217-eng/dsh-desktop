# 桌面增量增强 0.1.0

面向当前定制 DSH 0.2.1-alpha.4；不整体升级核心。统计页与插件更新作为独立包安装，原会话、人设、模型/API、插件及用户扩展保持原有归属。

- 对话的“统计”页：按轮次/步骤显示实际模型、输入/输出、缓存、首词延迟、模型用时、工具墙钟及压缩事务。通过宿主公开冷读接口加载有界日志窗口，不创建Agent、不调用模型、不复制聊天正文到独立数据库。缺失起点或usage显示未知；工具并行用时合并为墙钟，另保留调用用时合计。
- 设置的“插件更新”页：检查准确版本后再确认，只处理注册源中以原名安装的第三方包。本地源码、文件包、链接、内置和管理插件受保护。沿用原pluginManager移除、安装与恢复接口；先核对核心兼容性和原版本恢复来源，拒绝自动批准安装脚本。有运行中任务时不安装；实际安装期间新步骤等待完成，不中断在途模型或工具。安装失败或取消后尝试恢复准确旧版本并恢复原依赖范围；alpha.4热加载可能仍保留旧包代码，安装成功明确要求任务空闲时正常重启后生效，期间拒绝继续叠加更新；恢复失败明确显示，不宣称已成功。
- 更新只在明确确认时发生；不在启动或后台自动检查/更新所有插件。统计也没有后台轮询。

另有两个定向核心overlay：全局/项目指令分别计预算；切换小容量模型前用已提交的原模型整理历史，失败不提交新请求头。保留原分段摘要、断点续做、真实模型容量、账号接续、原工具历史和团队路由。

来源依据：官方 deepseek-ai/deepseek-harness 固定提交 ce7073d51254c26cd63b22a60835b8f948deb447。指令渲染器由该提交 packages/context/agent-instructions/src/render.ts 移植，沿用MIT许可证；其余增强按本地alpha.4公开接口实现。

构建：`node scripts/build-desktop-enhancements.mjs` 与 `node scripts/build-instruction-budget.mjs`。安装：`node scripts/install-desktop-enhancements.mjs DSH_HOME CORE_NODE_MODULES`。按任务空闲状态部署核心overlay，随后验证真实冷启动、原插件与界面。不能把源码测试或文件复制当成运行验收。
