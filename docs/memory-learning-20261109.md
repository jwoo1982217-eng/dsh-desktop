# DSH 对话自动学习验收

2026-11-09，电脑端 DSH 0.1.11 / core 0.2.2-rc.1 已安装知识库 0.4.0，并开启对话自动提炼。用户要求的是正常聊天后持续积累知识，不能只依靠“记住”指令。

正常本机主会话一轮完成后，后台沿用该轮实际模型，筛选有长期价值的内容，最多提出三条知识。新条目写入原知识库，继续使用统一检索、原笔记阅读/编辑、版本和回收站。没有第二份记忆数据库，也没有安装 Memory Brain 服务。

用户陈述和成功工具观测保留逐字证据、会话与事件来源；提炼摘要单独保存。助手自己的判断、假设和冲突条目进入“待核实”，核实前不进入知识召回或语义索引。用户陈述只是有出处的陈述，不代表已验证为普适事实。重复内容跳过；明确纠正仅在原版本仍一致时更新自动学习条目；人工笔记和并发编辑不被静默覆盖。删除过的自动学习内容会抑制重复入库。

设置入口：**更多 → 知识库 → 知识 → 记忆 → 对话自动学习**。当前每天最多 60 次后台提炼，可暂停或调整；会增加当前模型的请求用量。每轮最多一次提炼，45 秒超时，单队列串行；无效输出、来源变化或保存失败可在记忆页查看/重试。不会扫描补录全部旧聊天，QQ、云端和子代理会话不参与本轮功能；关闭或冻结记忆时停止提炼。不更改模型权重。
