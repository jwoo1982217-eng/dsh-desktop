# DSH 统一知识库与记忆星图验收

2026-11-08，已在本机电脑端 DSH 0.1.11 / core 0.2.2-rc.1 实装。入口：**知识库 → 知识 → 记忆 / 图谱**。

知识库搜索、星图、知识问答、原对话自动召回和按需工具共用 `Knowledge.memory`。继续使用原笔记、原摘要和原语义索引；没有安装第二套记忆数据库。明确记住/更正/遗忘采用真人原话、修订检查和原版本/回收站机制。后台整理只做可重建的原文摘录与目录，失败可重试。

实际验收：

- 17 篇笔记、6 条摘要、81 条原图谱关系；453 个旧会话及原插件保留。升级前选定的原数据与配置文件指纹一致。
- 相同范围、数量和字节预算下，知识库和星图返回一致的顺序；UI 显示关键词、语义和真实一跳关联依据。
- 星图结果打开原阅读窗口，编辑、版本历史、Markdown 导出及回收站保留。摘要编辑窗口打开并取消，原内容未改。原聊天草稿未发送或覆盖。
- 46 项测试通过，包含实际 rc.1 AgentLoop 模型请求捕获、纠正/关闭生效、范围、取消、损坏/容量失败、恢复、读租约和安装回退。
- 现有 apigo2 / deepseek-flash 完成 3 次真实知识库问答；最终混合检索问答返回有效原文编号，并指出原资料标题与正文条数不一致。
- 原全库检索对约135万片段在6秒内未完成；复用同代已校验来源缓存后，窄范围语义函数实测约0.4秒，最终已部署 HTTP 端到端约0.9秒，17个语义候选、无降级提示，首项为“模型路由使用说明”。这些是本次样例延迟，不是全面性能保证。

本阶段边界：关联最多一跳；当时后台没有自动抽取或确认新事实；全历史扫描仍受原6秒等待限制；真实问答与原生请求捕获不代表每个模型都会自动选择管理工具。已开启的跨项目/共享来源设置保持原样。

2026-11-09 后续已增加并开启对话自动提炼，真实对话自动入库与统一召回通过；待核实判断不直接用于回答。当前能力及验收边界见 [对话自动学习验收](memory-learning-20261109.md)。
