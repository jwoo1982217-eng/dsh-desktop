## Gemini 浏览器授权

公开版本不含默认 Google OAuth 客户端 ID 或客户端密钥。使用自己合法配置的 OAuth 客户端，在运行时环境设置：

- CMDC_PAK_GOOGLE_CLIENT_ID
- CMDC_PAK_GOOGLE_CLIENT_SECRET

不要在源码、日志或公开文件中填写实际值。环境缺失或为空时，授权会在启动监听与请求前给出缺项提示；补齐后使用原有授权流程。已有的授权码交换、state 校验、令牌续期和撤销流程保留。

桌面端将这两个变量设置在启动 Node 的环境中；手机源码构建者将其注入本机 Node 服务的私有启动环境。普通聊天和其他供应商可继续按原方式配置。仓库不内置任何使用者的账号、令牌、聊天、人设库或经验库。

发布过程未修改发布者原有本地工程、应用配置或 CNB 仓库。

## Loomy 账号应用访问配置

公开版本不再内置 Loomy 账号端点的应用 AccessKey ID 和 HMAC 签名密钥。需要执行短信或微信账号登录时，请在启动 Node 的本地私有环境中配置：

- `CMDC_PAK_LOOMY_ACCESS_KEY_ID`
- `CMDC_PAK_LOOMY_ACCESS_KEY_SECRET`

使用获授权的应用访问配置，不要把实际值提交到仓库。两项配置均会去除首尾空白；缺失或为空时，在账号请求发送前明确提示缺少哪个变量。模块和其他供应商仍可正常载入。应用 `appId`、公开客户端标识、端点和签名协议保持；已有用户 session 的业务与聊天请求不依赖这组应用密钥。

此前公开提交曾包含这组供应商应用访问凭据，它们不是使用者的个人 session。当前版本改用本地配置；仅从最新源码移除明文并不能清除旧提交、其他副本或缓存中的内容。历史记录是否另行清理由发布任务单独记录，本说明不宣称旧历史已经清除。
