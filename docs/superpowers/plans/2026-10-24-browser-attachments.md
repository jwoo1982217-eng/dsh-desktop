# DSH 浏览器附件链路实现与验收清单

目标：在现有共享登录浏览器面板中接通图片粘贴、文件拖拽、网页原生选文件请求，修复画面尺寸变化时的鼠标坐标错误。

范围由本聊天的失败案例及用户“把浏览器功能接完整”的要求确定；沿用现有浏览器、认证和标签所有权。音频播放、下载、系统权限弹窗不在本次附件链路范围内。

架构：面板读取用户主动选择的文件，以 128 KiB 文件块调用原有认证 RPC。临时文件仅在本机私有目录保存，单个 32 MiB、一次最多 8 个合计 64 MiB，全部暂存预留最多 128 MiB。未完成传输十分钟超时，已交付文件保留至本页离开或标签关闭。原生文件选择使用 Chrome 的 FileInput 接口，拖拽使用原生 DragEvent 接口；图片粘贴交给绑定的原评论框。网页导航后旧传输拒绝交付。

## 实现顺序

- [x] 记录输入指纹和原索引，保留其它窗口未完成修改。
- [x] 先运行缺少文件传输操作的失败用例，再实现暂存、分块、所有权、取消和清理。
- [x] 在真实 Chrome 中复现选文件缺失、旧画面坐标报错，再接入交付与视口转换。
- [x] 对旧面板运行剪贴板失败用例，再验证新面板的 FileReader、RPC 和网页附件预览完整链路。
- [x] 用失败用例检查焦点变化和重复提交，再绑定原控件、保持幂等及保留已交付的暂存。
- [x] 完成相邻边界和安装回退检查，阅读最终差异。
- [x] 只更新本任务的活动插件文件，验证 App 签名，并建立合并加载回执。
- [x] 等所有 DSH 任务空闲后加载，与 AutoClaw 修复共用一次后台重启；不打断正在运行的任务。
- [x] 通过本地测试页验收活动实例，保留回执并回收本任务临时产物。

验收必须确认网站收到的文件名和字节及实际图片预览，不能把按键发送或图片交付给网页当作远端上传成功。测试只向本机测试页传输构造文件，不向真实活动帖或第三方图床上传用户资料。
