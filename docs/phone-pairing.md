# 手机 DSH 连接电脑：Pocket 扫码

手机安装 [DSH 手机版 APK](https://cnb.cool/applecabal/dsh-phone)，电脑按 [安装说明](../desktop/README.md) 安装并启动。手机无需与电脑连接同一 Wi-Fi，可以使用流量。

## 推荐方式：在 DSH App 内扫码

电脑新安装器自带 Pocket 2.10.6，手机安装 **0.1.55 或更新版 APK**。

1. 电脑启动 DSH，打开「设置 → 手机访问」。
2. 人在外面时，点击「开启公网访问」，阅读并确认页面提示，等待公网二维码与访问密码出现。同一 Wi-Fi 内可使用局域网二维码。
3. 打开手机 DSH App，点顶部「电脑 → 扫码连接电脑（Pocket）」。首次使用允许相机权限，扫描电脑的二维码。
4. 扫码后在 App 内输入电脑页面显示的访问密码，打开电脑的会话、工作区和设置。

下次点顶部「电脑」即可打开保存的地址；点「手机」返回本机。也可在「服务 → 设备连接」粘贴 Pocket 访问链接、重新扫码或忘记这台电脑。连接记录只保存地址，不保存二维码里的访问密码。

手机重装后，需要在电脑「设置 → 手机访问」重新扫码。电脑原来的账号、聊天与文件仍保存在电脑上。临时公网地址重启后可能改变，重新扫描当前二维码即可；长期固定入口可使用 Pocket 的命名隧道设置。

电脑必须保持开机、联网且不休眠，DSH 与隧道继续运行。首次开启公网时，Pocket 会准备 cloudflared；若下载失败，在 Pocket 设置中指定已安装的 cloudflared 路径后重试。二维码与密码只交给要使用这台电脑的人。

## 原有加密配对方式

需要手机模型网关或普通 API 配置同步时，仍可使用原来的加密配对：

1. 电脑另开终端运行 `node scripts/start-home-relay.mjs`，复制输出的 `wss://…/relay` 中继地址。
2. 在电脑已登录 DSH 的浏览器打开 `/phone-peer`，粘贴中继地址，点击「生成连接链接」。
3. 手机点「服务 → 设备连接 → 原设备连接方式」，粘贴整个 `dsh-phone://peer/connect#…` 链接，再点「连接并打开电脑」。

电脑浏览器登录的 `?token=…` 链接、Pocket 的 HTTPS 访问链接与这里的加密配对链接各有用途。原加密方式详细说明见 [远程连接说明](../peer/README.md)。

## 选择模型与同步 API

电脑模式默认使用电脑自己的账号和模型。进入电脑「设置 → Jet Hub」配置；ChatGPT 会员授权要在电脑浏览器完成。

要把手机已有的普通 API 配置交给电脑，在手机本机的「服务 → 设备连接 → 原设备连接方式」使用「预览同步到电脑」，检查条目后再同步。自动同步默认关闭。已经同步成功的普通 API 可由电脑独立调用。

网页账号不会直接复制到电脑。若希望电脑调用手机登录的账号，手机允许已配对电脑调用网关，在电脑模型菜单选择「手机模型网关」。此时手机服务、模型网关与设备连接都要在线，手机供应商也需正常可用。

## 使用与关闭

家里的电脑应保持开机、联网且不休眠。Pocket 连接需要 DSH 和 Pocket 隧道在线；原加密配对需要 DSH 和密文中继在线。仅关闭浏览器不会停止服务；在启动终端按 Ctrl+C 停止 DSH，Pocket 设置中可关闭公网访问。

临时 Quick Tunnel 重启后地址可能变化。Pocket 用户重新扫码当前公网二维码；原加密用户更新中继地址并重新生成配对链接。原加密中继的固定入口见 [固定中继说明](../peer/README.md)。

断线时，已交给电脑的任务可能仍在运行。重连后先看同一会话的结果，避免重复发送同一个修改请求。远程操作遵守电脑 DSH 的现有权限与审批设置。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 电脑浏览器提示需要认证 | 使用本次启动终端打印的完整登录链接，或重新点启动脚本打开当前服务。 |
| 手机一直连接中 | 确认电脑、DSH 和 Pocket 隧道在线；临时地址变化时重新扫码。 |
| 手机仍显示旧对话 | 确认已经进入「电脑模式」，在菜单中选电脑的对应会话。 |
| 模型可列出但请求失败 | 检查执行端的账号授权、供应商状态；使用手机模型网关时也检查手机是否在线。 |
| 只能在家里 Wi-Fi 使用 | 扫描 Pocket 的公网二维码；局域网二维码适用于同一 Wi-Fi。 |

分享问题截图或日志前，遮住邮箱、号码、密钥、完整登录链接、完整配对链接和私人文件路径。公开仓库与使用说明不保存这些个人信息。
