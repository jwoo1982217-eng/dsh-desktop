# 手机连接电脑

电脑完成固定中继配置后，在 DSH 的设备连接页点击“连接手机”，复制连接链接。

在装有新版 DSH 的手机上点开链接，确认“连接这台电脑”。首次连接成功后，手机会记住配对；以后直接点“电脑”即可重连。

已配对的日常使用只需两步：电脑打开 DSH，手机打开 DSH 后点顶部“电脑”。手机里的“扫码连接电脑（Pocket）”是另一种入口；已选中“加密连接”的手机不需要每天重新扫码。

切换 Wi-Fi、流量或短暂断网后会尝试恢复连接。电脑需要开机并运行 DSH；电脑离线时，手机保留配对，待电脑上线后再点“电脑”。

配对已保存不等于当前已连通。固定中继的健康页正常也不能证明 WebSocket 已连通；排查时应核对两端的 `connected` 状态和中继连接错误。若云端明确返回免费额度耗尽，应保留配对并修正服务选型，不把每天等待重置作为长期使用方式。普通常驻服务见 [固定地址长连接服务](../remote-relay-node/README.md)。

查看或复制已有链接不会重新配对。主动重新生成配对或解除连接会使旧链接失效。连接链接可以授予电脑访问权限，请只发给自己的设备。

部署与管理员配置说明见 [固定中继部署说明](../remote-relay/README.md)。本次正式设备激活与验收状态以维护回执为准。
