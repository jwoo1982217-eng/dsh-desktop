# AI 网页与右侧栏

桌面 MCP 浏览器使用按项目与会话分配的后台面板。手动“浏览网站”使用另一个面板；工具打开成功不会自行创建前端侧栏。

桌面浏览器客户端现在订阅当前可见会话的事件源，只在 `mcp__browser__open` 对应的成功结果包含有效面板地址和活动标签时，通过正式侧栏资源接口打开“AI 网页”。查看器直接使用原面板，不复制网页或重新导航。会话切换会解除旧事件订阅；每个窗口记录已展示的结果序号，重复历史和普通更新不会反复展开用户收起的侧栏。

“AI 网页”与手动浏览器分别保留。收起或关闭查看器不会删除 AI 持有的标签；用户在网页标签上的关闭按钮仍会真正关闭该页。新版 HTML 在查看器卸载时暂停画面；客户端先于 Host 更新时，对旧 HTML 的同面板 `release` 请求做兼容转换，保留原页及表单。此兼容只作用于 AI 面板。

验证包括 `browser-sidebar-link.test.mjs` 的会话归属、重复结果、失败重试和卸载，以及 `browser-sidebar-link.chrome.test.mjs` 的实际 MCP 打开、官方侧栏控制器、真实 React 和 Chrome 画面、中文草稿、关闭恢复、新旧 HTML。此修复不改变网站账号、模型请求或其他插件。
