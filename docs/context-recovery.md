# 上下文整理与恢复

DSH 桌面核心仍为 0.2.1-alpha.4。维护入口是
`runtime/overlays/@deepseek-ai/dsh-compaction-basic/lib/`，新增模块由现有安装器和 macOS 打包器随覆盖目录一起复制。

## 长会话与切模型

没有指定独立摘要模型时，整理使用当前步骤选定的模型；手动 `/compact` 使用尚未消费的用户选择，再回退到上次实际请求。压缩模型可通过原有 `summarizationProvider` 和 `summarizationModel` 成对指定，原有按模型 `modelPolicies` 保持有效。不会自动寻找其他账号、切换供应商或改写模型标注容量。

自动整理在进入下一步前按该步骤的模型容量检查历史。旧模型自动设置的输出预算不会被带到新模型。用户在运行途中换模型时，当前整理继续使用已经捕获的步骤选择，后来的选择留给下一步。

## 分批摘要

输入估算使用保守文本计价，预留输出及输入余量；这不是上游 tokenizer 的精确读数。短历史保留原请求前缀。超长历史作为带角色、调用标识和结果的文本记录分批处理，摘要请求不执行工具。普通工具调用及结果成组；单条超长记录以明确编号的连续片段完整送入，避免静默截尾。

每批最多约 98K 估算 token，并受实际窗口限制。摘要过多时继续分层合并。只有上游明确报告上下文超限，才进一步缩小该分段。鉴权、额度、服务异常、输出截断和缺少结束标记都会保留原历史并报告失败。每次整理最多 64 次新请求，合并和拆分都有深度限制。

保留原系统要求、近期对话及完整工具配对边界。仍沿用 SDK 原有锁、变更检查和替换事务，完整摘要必须小于被替换的内容才能落入会话。原始事件仍保留在追加日志中。摘要是模型生成的任务交接材料，恢复后须核对当前文件、已有测试结果及未完成后台作业，不能据此盲目重放编辑、部署等操作。

## 独立恢复记录

实际任务存在工作目录且已设置 `DSH_HOME` 时，状态保存在：

```text
DSH_HOME/storage/context-recovery/<会话ID的SHA256>.json
```

记录包含来源摘要指纹、原始与近期用户要求的有限摘录、阶段、请求数及已成功分段。只复用请求内容、目标模型和预算都匹配的摘要；不会把其他任务或供应商的结果混用。文件仅本用户可读，原子更新；损坏、格式未知或身份不匹配的记录保持原样，当前操作重新整理。记录写入失败不冒充已持久化，也不关闭会话原有持久化。

`prepared` 只表示摘要生成完成，不能替代会话内 `compaction/summary` 和成功的 `compaction/end`，也不代表任务代码已完成或测试通过。新一次用户重试或 `/compact` 可以复用匹配分段，不自动创建任务或恢复有副作用的工具调用。

## 验证与部署

```sh
node --import ./scripts/desktop-test-imports.mjs --test scripts/compaction-recovery.test.mjs scripts/adaptive-compaction.test.mjs
```

`scripts/compaction-session-replay.mjs` 可用真实日志副本对照旧实现和新实现；该工具只使用本地受控适配器，回执不包含原文。它验证协议、预算和替换事务，实际云模型的摘要质量与真实服务验收另行完成。

部署前备份原程序与设置，检查运行任务及未保存输入；激活时只替换相关程序，保留账号、主副卡、模型设置和历史。macOS 应用资源更新须在副本完成，并重新核验签名。回退程序不等于回滚用户随后产生的会话与配置，禁止整目录覆盖用户数据。

此覆盖版本针对桌面 alpha.4。手机独立运行时使用另一版 SDK，须按手机升级契约单独适配和验收；手机连接到本电脑时使用这里的电脑后端。
